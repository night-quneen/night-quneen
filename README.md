# Night Queen — GitHub Pages Ready

এই folder-এর website টি GitHub Pages-এ সরাসরি publish করা যাবে।

## Files
- `index.html` — homepage + আপনার দেওয়া ad scripts
- `style.css` — responsive design
- `script.js` — mobile menu, search panel, year
- `assets/` — শুধু আপনার দেওয়া 13টি image

## GitHub-এ upload
1. GitHub এ নতুন repository বানান, যেমন `night-queen`.
2. এই folder-এর সব file repository root-এ upload করুন.
3. Repository → **Settings** → **Pages** যান.
4. **Build and deployment** → **Deploy from a branch**.
5. Branch হিসেবে `main` এবং folder `/ (root)` select করে **Save** করুন.
6. কিছুক্ষণ পরে GitHub Pages URL পাবেন.
